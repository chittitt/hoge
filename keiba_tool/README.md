# オッズ期待値チェッカー（keiba_tool）

ネット競馬（netkeiba）の出馬表とオッズを貼り付けると、オッズ期待値ベースの予想ルールに従って
**危険な人気馬・◎候補・穴候補・レースの勝負度** を判定するブラウザツールです。

## 起動方法

サーバー不要。`keiba_tool/index.html` をブラウザで開くだけで動作します。

```
# 例（macOS）
open keiba_tool/index.html
# 例（Windows）
start keiba_tool\index.html
# 例（Linux）
xdg-open keiba_tool/index.html
```

## 使い方

1. **STEP 1** — netkeiba の出馬表ページ（オッズ表示あり）で表をコピーして貼り付け、「出馬表を読み込む」。
   うまくパースできない場合は `馬番, 馬名, オッズ`（1行1頭）の簡易形式でも入力できます。
   読み込み後の表は直接編集可能です。
2. **STEP 2** — レース条件（クラス・2〜3歳戦・ハンデ戦・コース形態など）をチェックし、
   各馬について以下を判定します。
   - **実績はオッズに見合うか？** … 単勝10倍以下の馬は必ず検証。
     「見合わない（過剰人気）」＝危険な人気馬、人気薄で「見合わない（過小評価）」＝穴候補。
   - **記者の印が集中** … 重い印が集まった馬は期待値消滅のシグナル。
   - **能力と無関係な人気要因** … 馬名・馬主・血統・騎手人気で買われている場合。
   - **未知・データ不足** … むしろ買い材料としてプラス評価。
3. **「分析する」** を押すと以下が出力されます。
   - レースの勝負度スコア（勝負レース／検討／見送り）と加点理由
   - 危険な人気馬（消し・紐まで）
   - ◎候補（単勝3倍以上で期待値が取れる馬）
   - 単勝1倍台〜2倍台の◎対象外リスト
   - 穴候補
   - 想定オッズから3割下落した見送り対象
   - 馬券構築ヒント（人気−穴推奨、押さえの扱い、オッズ切り 等）
   - 資金管理（総資金の1/100〜1/1000の推奨賭け金）

## 組み込んでいる主なルール

- 単勝10倍以下の人気馬は実績とオッズの整合を検証し、納得できない人気＝危険な人気馬
- 危険な人気馬がいるレースが最も儲かる（他馬の期待値が自動上乗せ）
- 単勝1倍台〜2倍台前半は◎対象外、3倍以上なら人気馬でも◎
- 想定オッズから3割下落したら見送り
- 未知・データ不足は買い材料／少頭数・重賞・2〜3歳戦・ハンデ戦はオッズが甘くなりやすい
- 人気−穴の組み合わせが的中率と回収率のバランス最良
- 1レースの賭け金は総資金の1/100（可能なら1/1000）

※ 各判定の根拠（第◯回）はツール内の「判定ロジックを表示」から確認できます。
※ netkeiba のページ構成変更でコピペ形式が変わった場合は簡易形式を使ってください。
